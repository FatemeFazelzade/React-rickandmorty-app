# 🛸 Rick and Morty React App

A feature-rich web application built with **React** that lets users explore characters from the Rick and Morty universe using the official [Rick and Morty API](https://rickandmortyapi.com/).

## ✨ Features

- 🔍 **Real-time Character Search:** Search characters instantly with optimized API requests and `AbortController` cleanup.
- ❤️ **Favorites System:** Add or remove favorite characters with persistent storage using a custom `useLocalStorage` hook.
- 📱 **Interactive UI:** Detailed character views, custom modals, and clean responsive layout.
- ⚡ **Modern React Patterns:** Built using React Hooks (`useState`, `useEffect`), clean component structure, and robust error handling with `Axios` and `Sonner` toasts.

## 🛠️ Tech Stack

- **Frontend:** React, JavaScript (ES6+), CSS
- **Data Fetching:** Axios
- **State & Storage:** React Hooks, Custom `useLocalStorage` Hook
- **Notifications:** Sonner Toast library
